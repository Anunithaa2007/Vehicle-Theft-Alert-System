Vehicle Theft Alert System

Project Overview

The Vehicle Theft Alert System is an IoT-based security project designed to detect unauthorized vehicle access and immediately notify the vehicle owner.

The system uses ESP32, GPS, and Wi-Fi technologies to enhance vehicle security. When suspicious activity is detected, it activates a buzzer and sends an SMS alert to the owner's mobile phone using Twilio.

Objectives

- Detect unauthorized vehicle access.
- Provide instant alerts to the vehicle owner.
- Enhance vehicle security using IoT technology.
- Enable real-time theft notifications.

Hardware Components

- ESP32
- GPS Module
- IR Sensor
- Buzzer
- Servo Motor
- DC Motor (for engine simulation)

Software and Technologies

- Arduino IDE
- Embedded C/C++
- ESP32
- GPS
- Wi-Fi
- Twilio API

Working Principle

1. ESP32 acts as the main controller.
2. The IR sensor detects unauthorized access.
3. When suspicious activity is detected, the buzzer is activated.
4. An SMS alert is sent to the vehicle owner's mobile number using Twilio.
5. GPS is used to obtain vehicle location information.

Key Features

- Unauthorized access detection.
- Real-time SMS notifications.
- Buzzer-based alert system.
- IoT-based vehicle monitoring.
- GPS integration.
